# 🍰 Doce Arte

Bem-vindo(a) ao **Doce Arte** — um projeto de site vitrine para uma loja de doces artesanais, desenvolvido com **HTML**, **CSS** e **JavaScript**.  
A proposta é oferecer uma experiência visual agradável, apresentando os produtos de forma organizada e atraente para os clientes.
